# 贪吃蛇网页小游戏设计

## 目标
为用户制作可直接通过公网网址游玩的中文贪吃蛇小游戏，兼容电脑和手机。使用纯 HTML、CSS 和 JavaScript，无后端、无运行时第三方依赖。

## 页面与操作
深色霓虹风格。页面显示游戏画布、当前分数、本机最高分、状态提示及开始、暂停/继续、重新开始按钮。电脑支持方向键和 WASD；手机支持画布滑动和方向按钮。窄屏布局不产生横向滚动，触控游戏区域不触发页面滚动。

## 游戏规则
使用 20×20 方格，每 140 毫秒前进一格，初始蛇长 3、向右移动。食物只在空格生成；吃到食物增长一格并加 10 分。撞墙或撞到身体结束；允许进入本回合即将移走的尾格。每个移动周期最多接受一次转向，禁止直接反向。填满棋盘显示胜利，不再生成食物。

开始前等待操作，暂停时停止移动，重新开始清空当前局面和分数。切换到后台自动暂停，返回后由用户继续。最高分保存在 localStorage；存储不可用时仍可正常游戏，仅当前会话保留最高分。

## 结构
index.html 负责语义化页面；styles.css 负责响应式样式；game.js 负责可独立测试的状态和移动规则；app.js 负责绘制、输入、计时和存储。使用 Node 内置测试工具验证游戏规则，无须构建即可静态部署。

## 验证
自动测试覆盖移动、吃食物、反向和连续转向、墙和身体碰撞、尾格移动及满盘胜利。浏览器验证开始、暂停、重开、键盘和触控操作、分数存储与手机尺寸布局；通过本地 HTTP 请求检查静态资源。

## 公网发布
优先使用当前 GitHub 仓库的 GitHub Pages。先验证实际写入和 Pages 管理能力；不绕过认证，不输出凭据。若发布权限不足，完成并测试游戏，报告需要用户执行的最小授权操作。只有公网地址实际返回游戏页面后才宣称上线成功。
