# 贪吃蛇 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 实现兼容手机和电脑的中文贪吃蛇，完成测试并尝试发布可访问的公网网址。

**Architecture:** 纯静态页面，游戏状态与浏览器适配分离。无需后端或构建，支持 GitHub Pages 子路径。

**Tech Stack:** HTML、CSS、JavaScript ES modules、Node 内置测试工具；浏览器自动化工具仅用于验证。

**Spec:** docs/superpowers/specs/2026-10-15-snake-design.md

## Global Constraints
- 无后端、无运行时第三方依赖。
- 使用 20×20 方格，每 140 毫秒前进一格，初始蛇长 3、向右移动。
- 食物只在空格生成；吃到食物增长一格并加 10 分。
- 每个移动周期最多接受一次转向，禁止直接反向。
- 允许进入本回合即将移走的尾格；填满棋盘显示胜利。
- 不绕过认证，不输出凭据；只有公网地址实际返回游戏页面后才宣称上线成功。

## Review Focus
- 连续输入两次方向不能在一次移动周期内反向。
- 浏览器存储被禁用时游戏仍可运行。
- 暂停、后台及重开不能残留重复计时器。
- 320px 窄屏无横向滚动，滑动和按钮均可操作。
- GitHub Pages 子路径下脚本和样式能正确加载。
